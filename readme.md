# Landing Page - Psicóloga Giulia Rivolta

**Esta é uma landing page profissional** desenvolvida para a Psicóloga Giulia Rivolta, com o objetivo de centralizar informações sobre sua atuação clínica, especialidades (Terapia Cognitivo-Comportamental) e facilitar o agendamento de consultas.

### 🔗 [Deploy do projeto] (https://psicologagiuliarivolta.com.br/)

## 📌 Sobre o projeto

O projeto foi focado em conversão e experiência do usuário. A página apresenta de forma clara a trajetória da profissional, as principais demandas atendidas e um FAQ para sanar dúvidas comuns de novos pacientes.

# Tecnologias e Ferramentas

HTML5 & CSS3 (Semântica e Estilização)

JavaScript (Manipulação de DOM e Interatividade)

SEO (Search Engine Optimization): Otimização de meta-tags

# Funcionalidades

Design Responsivo: Adaptado para leitura confortável em dispositivos móveis e desktops.

Seção de depoimentos:Depoimentos foram colocados de forma extremamente organizada em um carrosel

Seção de Especialidades: Exposição clara das áreas de atuação (TCC, Ansiedade, Depressão, etc.).

Seção de FAQ: Acordeões interativos para dúvidas frequentes.
